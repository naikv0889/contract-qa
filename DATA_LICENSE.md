# Dataset attribution

The contract text and lawyer annotations are from CUAD v1, maintained by The
Atticus Project: https://github.com/TheAtticusProject/cuad

CUAD is distributed under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

This repository extracts a deterministic 25-contract subset and transforms
the source into normalized clause chunks and a five-category evaluation set.
The source contract text is preserved in `data/contracts/`; chunks normalize
spacing and remove source/page noise. These are adaptations of CUAD. No
endorsement by The Atticus Project is implied. Code is separately MIT licensed.
